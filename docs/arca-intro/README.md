# 소개글 사용 안내

- `상황극_탐색기_소개글.html`: 업로드된 이미지 주소와 다운로드 버튼이 반영된 아카라이브 붙여넣기용 HTML
- `상황극_탐색기_소개글-미리보기.html`: 같은 내용을 로컬에서 확인하는 파일
- `상황극_탐색기_소개글.md`: Markdown 소개문
- `screenshots/`: 업로드할 원본 PNG
- `상황극_탐색기_스크린샷.zip`: 이미지 업로드용 묶음

플러그인 버튼은 GitHub Release 첨부 파일을 현재 창에서 내려받고, 모듈 버튼은 Proton Drive 공유 폴더를 엽니다. 버튼은 아카라이브의 외부 CSS 없이도 보이도록 표 셀 배경색과 인라인 링크 스타일을 함께 사용합니다.
