# 상황극 탐색기

짧은 상황극을 검색하고 골라 현재 채팅에 지침으로 넣는 RisuAI API v3 플러그인입니다. 532개 상황극이 든 **상황극 서고** 모듈과 함께 사용합니다.

## 주요 기능

- 검색·분류·정렬과 19금 표시 설정
- 일반봇 원문 입력과 시뮬봇 대상 이름 치환
- 바로 채팅에 추가하거나 인풋카드에서 수정
- 모바일 전체 화면, 태블릿·PC 중앙 패널

## 다운로드

- [플러그인 다운로드](https://github.com/canister2668/risuai-scenario-library/releases/download/v1.0.0/scenario-library.plugin.js)

모듈을 먼저 가져온 뒤 플러그인을 설치합니다. 채팅 입력창 오른쪽 햄버거 메뉴에서 **상황극 탐색기**를 열고 사용할 상황극을 고르면 됩니다.
