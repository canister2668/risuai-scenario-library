상황극 탐색기

짧은 상황극을 검색하고 골라 현재 채팅에 지침으로 넣는 플러그인입니다. 532개 상황극이 든 상황극 서고 모듈과 함께 사용합니다.

실시간 웹 검색 없이 모듈 안의 로어북 정보를 불러옵니다.

아카챈 로어북 탭 자료를 모았으며, 게시자가 삭제를 요청하면 해당 자료를 내립니다.

주요 기능

빠른 탐색 · 검색·분류·정렬·19금 표시 설정
두 가지 모드 · 일반봇 원문 또는 시뮬봇 대상 치환
간편 입력 · 바로 추가하거나 인풋카드에서 수정

화면 미리보기

본문은 모듈에 저장되며 플러그인 저장소는 검색용 캐시로 활용됩니다.

다운로드

모듈을 먼저 가져온 뒤 플러그인을 설치해 주세요.

플러그인 다운로드
모듈 다운로드

사용법

  1. RisuAI에서 상황극 서고 모듈과 상황극 탐색기 플러그인을 가져옵니다.
  2. 채팅 입력창 오른쪽 햄버거 메뉴에서 상황극 탐색기를 엽니다.
  1. 상황극을 고르고 일반봇 또는 시뮬봇을 선택해 채팅에 추가합니다.

원문 링크를 길게 누르면 원작자 게시글을 새 창으로 열 수 있습니다.
